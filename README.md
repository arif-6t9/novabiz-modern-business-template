# NovaBiz V3 — Modern Business HTML Template

NovaBiz V3 is a polished, responsive, multi-page business template built with HTML5, CSS3 and Vanilla JavaScript.

## Pages
Home, About, Services, Portfolio, Blog and Contact.

## Structure
NovaBiz-V3/
- index.html
- about.html
- services.html
- portfolio.html
- blog.html
- contact.html
- css/style.css
- js/script.js
- assets/images/
- assets/icons/
- documentation/index.html
- README.md

## Contact Form
The form uses `YOUR_FORM_ENDPOINT` intentionally. Replace the `action` value in `contact.html` with your own backend or form service. No author email address is hardcoded.

## Customization
Replace neutral demo content, contact details, services, portfolio items and blog content. Global colors are at the top of `css/style.css`.

## Assets
The SVG illustrations included in `assets/images` are neutral demo graphics and can be replaced with project-specific images.
