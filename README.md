# NovaBiz

## Modern Business HTML Template

NovaBiz V2 is a clean, modern and responsive HTML template designed for businesses, agencies, startups, consultants, freelancers and professional services.

---

## Features

- Modern business design
- Fully responsive layout
- Mobile navigation
- Hero section
- Services section
- About section
- Statistics section
- Testimonials section
- Call-to-action section
- Contact section
- Functional contact form
- Vanilla JavaScript
- Lightweight structure
- Easy customization
- No framework required
- No build process required

# Installation

No installation or build process is required.

1. Extract the ZIP package.
2. Open the extracted folder.
3. Open `index.html` in a modern web browser.

# Contact Form

NovaBiz uses FormSubmit to process contact form submissions.

The form is configured with:

`https://formsubmit.co/arifyt3595@gmail.com`

The JavaScript does not display a fake success message.

A success message is displayed only after the form service returns a successful response.

---

## Changing The Email Address

If the buyer wants to use another email address, open:

`index.html`

Find:

`https://formsubmit.co/arifyt3595@gmail.com`

Replace the email address with the buyer's own email address.

Example:

`https://formsubmit.co/your-email@example.com`

---

## FormSubmit Activation

The first time the form is submitted to a new email address, FormSubmit may require email confirmation.

Follow the confirmation instructions sent by FormSubmit.
