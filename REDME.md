# NovaBiz V2

Modern Business HTML Template

Designed & Developed by ARIF

---

## Overview

NovaBiz is a clean, modern and responsive
business HTML template created for:

- Startups
- Agencies
- Companies
- Consultants
- Creative businesses
- Small businesses
- Landing pages

The template is lightweight and easy to customize.

---

## Features

- Responsive design
- Modern business layout
- Mobile navigation
- Hero section
- Services section
- About section
- Statistics section
- Testimonials
- Call-to-action section
- Contact form
- Smooth scrolling
- Clean CSS
- Vanilla JavaScript
- No framework required
- Easy customization
- Documentation included

## Installation

No installation is required.

1. Extract the ZIP file.
2. Open the project folder.
3. Open index.html in your browser.
