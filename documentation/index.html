Customization

Edit the HTML pages to replace neutral demo content. Edit the CSS variables at the top of css/style.css for colors.

Contact Form

Replace YOUR_FORM_ENDPOINT in contact.html with your own backend or form service. The template contains no author email endpoint.

Deployment

Upload the complete folder while preserving its structure. The homepage is index.html.
