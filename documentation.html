NovaBiz Documentation

Modern Business HTML Template — Version 2.0

1. Introduction

Thank you for purchasing NovaBiz. NovaBiz is a modern, responsive and easy-to-customize HTML website template.

The template is suitable for businesses, startups, agencies, consultants and creative companies.

3. Installation

No installation or build process is required.

  1. Extract the ZIP file.
  2. Open the project folder.
  3. Open index.html in your browser.

You can also upload the complete folder to any standard web hosting service.

4. Customization

Website Name

Open index.html and search for: 

NovaBiz

Replace it with your own brand name.

Colors

Open: 

assets/css/style.css

At the beginning of the stylesheet, you will find the main CSS variables. 

--primary: #635bff;
--primary-dark: #5148e8;
--text: #172033;

Change these values to customize the template colors.

5. Navigation

Navigation links are located inside the header section of index.html.

You can add, remove or rename navigation items according to your project.

6. Contact Form

The contact form currently uses JavaScript for a demo submission message.

To receive real messages, connect the form to your preferred backend or form service.

7. Responsive Design

NovaBiz is designed to work on desktop, tablet and mobile screen sizes.

Responsive styles are included in: 

assets/css/style.css

8. Browser Support

The template is designed for modern browsers including Chrome, Edge, Firefox and Safari.
